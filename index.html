What's running right now

Takhti is one app with three tiers. The child never sees a tier — they see a lesson that always works and quietly gets richer.

TIER 0 Always on-device

Reading diff, stroke scoring, problem generation, adaptive level, progress. Deterministic. Zero network, ever.

TIER 1 On-device model

Small language model on the NPU. Fresh practice sentences, kid-language explanations of a mistake. Optional — app is complete without it.

TIER 2 Opportunistic cloud

Never serves today's lesson. Answers the question queue and pre-loads tomorrow's content whenever a signal appears.

Prototype note: in the browser, speech recognition routes through the Web Speech API and needs a connection. On Android this is replaced by an on-device recognizer, which is why the reading loop has a keyboard fallback built in.
